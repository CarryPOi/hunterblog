融合的了怪物猎人世界与个人博客所搭建的静态网站
核心框架与构建工具：
Vue 3 (^3.5.34): 核心前端框架，用于构建用户界面。
Vite (^8.0.12): 现代化的前端构建工具，提供极速的冷启动和热更新功能。
Vue Router (^4.6.4): Vue 官方的路由管理器，用于处理页面切换和单页应用（SPA）导航。
Pinia (^3.0.4): Vue 的专属状态管理库，作为 Vuex 的现代替代方案。
辅助与功能库：
VueUse (@vueuse/core ^14.3.0): 强大的 Vue 组合式 API (Composition API) 实用工具集。
GSAP (^3.15.0): 业界领先的 JavaScript 动画库，用于实现复杂且高性能的界面交互与动画。
ECharts (^6.1.0) 配合 vue-echarts (^8.0.1): 用于实现丰富的数据可视化图表。
Marked (^18.0.5): 高性能的 Markdown 解析器，用于将 Markdown 文本渲染为 HTML。
部署与 CI/CD：
GitHub Actions: 使用了 GitHub Actions 进行持续集成与自动化部署。
